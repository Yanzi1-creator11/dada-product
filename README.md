# 搭哒 同校找搭子平台

搭哒是一款面向同校用户的找搭子产品，覆盖运动、学习和娱乐三类场景。

产品通过结构化需求、明确规则筛选、多人邀请和安排版本确认，帮助用户完成从“想找个人一起”到“所有成员确认同一安排”的完整流程。

## 核心能力

- 运动、学习、娱乐三类需求发布
- 基于同校、事项、时间、参与方式和偏好的规则筛选
- 真实空结果，不编造推荐
- 多人邀请、三小时有效期和并发名额控制
- 已找齐不自动关闭，成员退出后恢复名额
- 活动安排版本与逐人确认
- 联系方式主动公开与隐私控制
- AI 破冰话术可编辑、可复制、不代发
